# SuperAmiBot — Telegram-бот с идеями для досуга

**SuperAmiBot** — Telegram-бот на Python, который предлагает пользователю случайные занятия в зависимости от его настроения и возраста.

Проект создан для практики разработки Telegram-ботов с использованием библиотеки aiogram.

## Возможности

- Регистрация пользователя через Telegram.
- Ввод и сохранение возраста пользователя.
- Выбор одного из восьми вариантов настроения.
- Случайный подбор занятия из соответствующей категории.
- Фильтрация отдельных заданий по возрасту.
- Изменение возраста и настроения с помощью кнопок.
- Сохранение возраста между запусками бота.

В проекте предусмотрено 160 идей для занятий — по 20 в каждой категории настроения.

## Технологии

- Python
- aiogram 3
- asyncio
- FSM (Finite State Machine)
- JSON для хранения возраста пользователей
- pytest для автоматического тестирования

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/SuperAmiBot.git
cd SuperAmiBot
```

Вместо `YOUR_USERNAME` укажите свой логин GitHub.

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows:

```bash
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
python -m pip install aiogram python-dotenv pytest
```

### 4. Настройка токена

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token
```

Получите токен своего бота через [@BotFather](https://t.me/BotFather) в Telegram и укажите его вместо `your_telegram_bot_token`.

**Не публикуйте токен в открытом доступе.**

### 5. Запуск бота

```bash
python main.py
```

Компьютер должен оставаться включённым, а процесс бота — запущенным, чтобы бот отвечал на сообщения.

## Тестирование

Для запуска автоматических тестов выполните:

```bash
python -m pytest -v
```

Тесты проверяют определение возрастных групп и работу возрастной фильтрации заданий.
